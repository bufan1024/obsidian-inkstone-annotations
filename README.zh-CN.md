为 Obsidian 笔记提供下划线、四色高亮、脚注备注、当前笔记标注侧栏与摘录导出。插件版本为 **1.1.7**，配套 Inkstone 主题版本为 **1.3.7**，最低 Obsidian 版本为 **1.10.6**。

标注直接保存在当前 Markdown 中，兼容旧版 Inkstone 标记。插件只使用本地 Obsidian API，不调用网络，不需要账户或其他插件；实时预览使用 Obsidian 自带的 CodeMirror，用户无需安装依赖。Inkstone 主题仍是纯 CSS，可独立使用。


**社区目录状态（2026-10-21）：** 插件自动审核已完成（**Completed**），[公开页面](https://community.obsidian.md/plugins/inkstone-annotations)显示 **Review Satisfactory**，**Add to Obsidian** 已可用。打开页面 → 点击 **Add to Obsidian** → 在 Obsidian 中按提示安装并启用。GitHub Release 手动安装仍可作为备选。Inkstone 主题尚未提交。

## 安装与更新

手动安装时，将插件的三个运行文件放到以下目录：

```text
你的笔记库/
└── .obsidian/
    └── plugins/
        └── inkstone-annotations/
            ├── main.js
            ├── styles.css
            └── manifest.json
```

在「设置 → 第三方插件」关闭「受限模式」，手动启用「Inkstone Annotations」。未出现在列表中时，重启 Obsidian，并检查目录是否多嵌套了一层。`.obsidian` 是隐藏目录；使用自定义配置文件夹时替换为实际名称。独立主题包不包含 JavaScript，也不会添加操作入口。

更新前关闭 Obsidian 并备份旧文件，只替换上述三个文件，保留 `data.json`。使用[上游主题仓库](https://github.com/bufan1024/obsidian-inkstone)或合集中的安装脚本时（本独立插件仓库不含安装器），可运行 `python3 scripts/install.py --vault "/你的笔记库路径" --update --plugin-only`，先加 `--dry-run` 可查看计划。它保留当前主题、配色、行宽偏好和插件数据，不会自动启用插件。完整步骤见[安装与更新教程](https://github.com/bufan1024/obsidian-inkstone/blob/main/INSTALL.md)。

## 添加标注与备注

1. 在笔记中选中同一源代码行内的普通文字。屏幕自动折行不影响选择，不要跨越手动换行。
2. 只需划线时，点击快捷条的「划线」，沿用最近的样式和颜色；要换样式，点击相邻箭头「划线样式」，选择下划线或黄、绿、蓝、粉色高亮，即可保存。
3. 需要备注时，在选中文字后点击「写想法」，直接在原文旁的小浮层中查看原文预览、输入多行想法，并选择黄、绿、蓝、粉色高亮或下划线。新普通选区默认下划线；已有标注默认当前样式，不改样式时会保留原有标记。
4. 点击「保存想法」，或按 `Cmd+Enter`（macOS）、`Ctrl+Enter`（Windows/Linux），一次保存选定的样式与脚注备注。输入期间切换样式不丢失文字，也不提前写入笔记；「取消」不写入任何样式或备注。

「写想法」就是添加备注，作为原生脚注保存在当前文件文末。点击正文脚注编号可跳转到备注，脚注处的返回链接可回到正文。

命令「墨读：标注与备注」「墨读：添加备注」、右键「墨读：标注与备注…」和左侧荧光笔图标仍打开完整面板，可同时选择样式和填写备注。在完整面板中点击「保存标注」或按 `Cmd+Enter` / `Ctrl+Enter` 保存，取消不会写入笔记。

阅读视图支持同一源代码行的简单段落，可在已有 Inkstone 标记和脚注旁继续标注其他普通文字，不必为每次标注切换视图。含链接、加粗等复杂 Markdown 的段落仍请切到编辑视图，选择具体位置的普通文字。

## 编辑或移除已有标注

点击阅读视图或实时预览中显示的现有高亮、下划线，会在原文旁弹出小菜单；标记获得键盘焦点后，按 `Enter` 或空格也能打开。点击侧栏的「编辑」，会在该按钮旁打开相同的小菜单。

- 直接选择黄、绿、蓝、粉色或下划线，立即修改整条标注。当前样式显示选中提示。
- 点击「写想法」，在小菜单内查看原文预览、输入多行备注并选择样式；已有备注时显示「编辑想法」。默认选中当前样式，不改时会保留原有标记。此处切换样式只更新草稿，保留已输入的文字；点击「保存想法」或按 `Cmd+Enter` / `Ctrl+Enter` 后，样式与备注一起生效。「取消」不写入任何样式或备注。
- 点击「删除标注」移除标记并保留原文。

点击外部、按 `Esc`、滚动或切换笔记会收起小菜单。阅读视图右键的编辑入口与综合编辑命令仍打开完整面板，可同时修改样式与备注。

在编辑视图中，将光标放入已有标记的正文，或选中其部分正文，再执行标注命令，会修改整个已有标记，不会嵌套一层标记。不要把 HTML 标签本身包含在选区中。

移除标注会保留原文，只清理不再被其他位置引用的 Inkstone 专属脚注。若多个位置共享同一备注，移除其中一个标记不会删除其余位置需要的备注；单独修改其中一个标记的备注，会为它建立独立脚注。

## 实时预览与源码模式

实时预览（Live Preview）中，光标和选区离开标注范围后，显示实际高亮或下划线；光标或选区进入范围时显示原 HTML 源码，便于直接编辑。源码模式始终显示原始内容。此显示切换不改写保存格式，也不需要转换旧笔记。

## 当前笔记侧栏与摘录导出

执行「墨读：打开标注侧栏」，或点击快捷条的「更多 → 打开标注侧栏」。侧栏仅列出当前 Markdown 笔记的标注，显示摘录、颜色或下划线样式及备注，并随笔记修改刷新。

顶部显示当前笔记名、所在目录和标注数量；悬停路径可查看完整位置。摘录与想法分层显示，定位、编辑和删除按钮始终可见。列表可单独滚动，顶部的筛选与导出入口保持可见。

- 使用顶部筛选框查看某一种颜色或下划线。
- 「定位原文」跳到标记位置；「编辑」在按钮旁打开[标注小菜单](#编辑或移除已有标注)，首层改色立即生效，写／编辑想法在同一浮层内保存，取消不写入；「删除」移除标注并保留原文。
- 切换到另一篇笔记时，侧栏跟随当前笔记。侧栏不是全库搜索或标注索引。

侧栏「导出摘录」按钮、快捷条「更多 → 导出当前笔记摘录」及同名命令会导出当前笔记的**全部标注**，不受侧栏颜色筛选影响。新文件与原笔记放在同一目录，包含标注原文、备注和返回原笔记的来源链接。

文件名为 `原笔记名-墨读摘录.md`；已有同名文件时，依次尝试 `原笔记名-墨读摘录-2.md` 等名称。导出会新建文件并打开，不覆盖原笔记或以前的摘录。摘录是当时的副本，不随原笔记自动同步。

## 快捷条、阅读设置与翻页

有效选区后会显示快捷条，操作时保留选区。首层提供「复制」「划线」「写想法」和「更多」；划线旁的箭头展开带文字的小色点与下划线选项，选择后立即保存。「划线」沿用最近的样式和颜色，已有标记则保留现有样式；「写想法」直接打开含原文预览、多行输入框和样式选择的小浮层，点击保存后样式与备注一起生效。已有标记还可从「更多」移除。直接点击正文中的现有标记，会打开[标注小菜单](#编辑或移除已有标注)。

快捷条字号独立于正文，位于选区上方，空间不足时移到下方，也提供触控入口。按 `Esc` 或滚动可收起；在插件设置中关闭「快捷标注条」后，仍可使用右键菜单和命令面板。

字号和字体使用 Obsidian「设置 → 外观」的原生控制。Inkstone 主题仍支持 CSS 变量 `--inkstone-font-size` 显式覆盖字号；要恢复原生字号，请移除已有的该变量。

插件设置中的行高和行宽预设用于 Inkstone 主题：

| 设置 | 选项 |
| --- | --- |
| 阅读行高 | 跟随主题 / CSS、1.5、1.75、2.0 |
| 阅读行宽 | 跟随主题 / CSS、32em、40em、48em |
| 恢复阅读预设 | 恢复主题或 CSS 的行高与行宽，保留原生字号和字体 |

使用行宽预设时，请开启「设置 → 编辑器 → 可读行宽」。如果用 CSS 自定义行高、行宽，将插件预设设为「跟随主题 / CSS」。

执行「墨读：上一屏／下一屏」，或点击状态栏 ↑／↓，按当前内容视口高度立即滚动，并保留少量上下文。阅读视图和编辑视图都可使用；这不会给笔记插入分页符。翻页命令没有默认快捷键，可在「设置 → 快捷键」中自行绑定。

## 完整命令与撤销

插件提供 13 个命令，均可在命令面板中查找并自行绑定快捷键：

| 命令 | 操作 |
| --- | --- |
| 墨读：标注与备注 | 打开标注面板，记住最近使用的样式和颜色 |
| 墨读：添加下划线 | 直接划线，或将现有标注改为下划线 |
| 墨读：黄色高亮 | 直接添加或改为黄色高亮 |
| 墨读：绿色高亮 | 直接添加或改为绿色高亮 |
| 墨读：蓝色高亮 | 直接添加或改为蓝色高亮 |
| 墨读：粉色高亮 | 直接添加或改为粉色高亮 |
| 墨读：添加备注 | 打开面板填写备注，默认使用下划线 |
| 墨读：切换彩色／灰阶标注 | 切换当前显示方式，不改保存的颜色 |
| 墨读：撤销上次标注 | 撤销最近一次添加、编辑或移除标注 |
| 墨读：打开标注侧栏 | 查看当前笔记标注 |
| 墨读：导出当前笔记摘录 | 新建含全部标注、备注及来源的 Markdown |
| 墨读：上一屏 | 向前滚动一屏，保留少量上下文 |
| 墨读：下一屏 | 向后滚动一屏，保留少量上下文 |

编辑视图可以使用系统撤销与重做：`Cmd+Z` / `Ctrl+Z` 及系统对应的重做快捷键。每次标注的正文与脚注修改作为一次编辑操作处理。

阅读视图可执行「墨读：撤销上次标注」。它只保留本次启用插件以来的最后一次标注操作，须在同一笔记且之后没有其他修改时使用；若有其他编辑，请切换编辑视图使用系统撤销。它不提供多步标注历史，也不负责删除导出的摘录文件。

## 彩色与墨水屏显示

默认使用浅色高亮底色与深色正文。开启面板或插件设置中的「墨水屏显示」后，四色统一为浅灰底，并通过底线保留区别：

| 高亮颜色 | 灰阶底线 |
| --- | --- |
| 黄色 | 实线 |
| 绿色 | 双线 |
| 蓝色 | 点线 |
| 粉色 | 虚线 |

切换显示不会改变 Markdown 中保存的颜色，之后可恢复彩色。插件关闭后，Inkstone 主题仍能显示保存的 HTML 标记与原生脚注。

## 保存格式与保护范围

下划线和高亮使用 HTML，备注使用 Obsidian 原生脚注，继续兼容旧版格式：

```md
<u class="inkstone-underline">需要回头思考的句子</u>[^inkstone-demo-1]

<mark class="inkstone-highlight inkstone-yellow">值得记住的观点</mark>

[^inkstone-demo-1]: 我对这句话的理解。
```

颜色类名为 `inkstone-yellow`、`inkstone-green`、`inkstone-blue`、`inkstone-rose`。可以在源码模式直接编辑标记与脚注。普通脚注可以共享；保留其余引用时，插件不会删除共享定义。

选区应仅包含同一源代码行内的普通正文。插件保护 HTML 标签及属性、链接目标、代码、公式和属性区；不接受跨行选区或包含完整 Markdown / HTML 格式的选区。标题、列表和引用的结构符号应留在选区外。遇到提示时，切换编辑视图并缩小到普通文字后重选。

阅读视图按原生渲染器提供的源段落位置和逐字符映射定位，重复词语可区分；复杂 Markdown、未知 HTML 或跨源行段落继续要求切到编辑视图。菜单或面板打开后切换笔记、关闭插件或修改原文，保存会被拒绝，需要重新选择。

复制 [划线与备注示例](examples/划线与备注示例.md) 到笔记库，可练习同段多次标注、编辑、侧栏和导出。测试范围见项目[验证记录](https://github.com/bufan1024/obsidian-inkstone/blob/main/VALIDATION.md)。窄屏与触控事件测试不等于手机原生应用或实体墨水屏实测，两类设备尚未验证。

## 开发与许可

使用 Node.js 22 或更新版本，无需安装依赖：

```sh
node build.mjs
node --test tests/*.test.cjs
```

也可运行 `npm run build` 和 `npm test`。构建仅使用本仓库的 `src/` 和 `manifest.json`，生成 `main.js` 与 `styles.css`。

插件源码只在[上游 annotations 目录](https://github.com/bufan1024/obsidian-inkstone/tree/main/annotations)维护。请在那里提交源码修改，再用上游 `scripts/export_plugin.py` 重新导出此发行仓库，避免维护两份不同的源码。本地示例是上游示例的导出副本。
