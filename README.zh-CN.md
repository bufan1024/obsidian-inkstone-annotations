为 Obsidian 笔记提供下划线、四色高亮、脚注备注、当前笔记标注侧栏与摘录导出。插件 **1.2.0** 已发布，新版本市场同步与审核状态以插件市场页面为准。配套主题 **1.4.0** 已在 [GitHub Release](https://github.com/bufan1024/obsidian-inkstone/releases/tag/1.4.0) 发布，市场同步与审核状态以主题市场页面为准。最低 Obsidian 版本仍为 **1.10.6**。

标注直接保存在当前 Markdown 中，兼容旧版 Inkstone 标记。插件只使用本地 Obsidian API，不调用网络，不需要账户或其他插件；实时预览使用 Obsidian 自带的 CodeMirror，用户无需安装依赖。Inkstone 主题仍是纯 CSS，可独立使用。

## 安装与更新

### 推荐：从 Obsidian 市场安装

先在 Obsidian 中打开要使用的笔记库。市场安装不需要 Git、Python 或构建步骤。主题与插件是两个独立组件，按需要分别安装：

- **标注插件：** 打开「设置 → 第三方插件（Community plugins）」，首次使用时如有需要，关闭「受限模式（Restricted mode）」。点击「浏览（Browse）」，搜索 **Inkstone Annotations**（插件 ID：`inkstone-annotations`），点击「安装（Install）」后，再点击「启用（Enable）」。也可在「已安装插件（Installed plugins）」中打开插件开关。
- **配套主题：** 打开「设置 → 外观 → 主题 → 管理（Manage）」，搜索 **Inkstone**，点击「安装并使用（Install and use）」。主题仅支持浅色（**Light only**），请将配色设为浅色。只使用标注插件时无需安装主题。

也可以打开上方的市场页面，点击 **Add to Obsidian**，在目标笔记库中继续安装；安装主题不会自动安装或启用插件。启用后，选中同一源代码行内的普通文字，应出现「划线」「写想法」快捷操作；也可在命令面板中搜索「墨读：打开标注侧栏」。

### 在市场更新单个组件

- **只更新插件：** 打开「设置 → 第三方插件 → 检查更新（Check for updates）」，在「已安装插件」中只点击 **Inkstone Annotations** 旁的「更新（Update）」。更新完成后确认其开关仍为启用。
- **只更新主题：** 打开「设置 → 外观 → 主题 → 管理」，选择 **Inkstone**；如显示「检查更新（Check for updates）」，先点击检查，再点击「更新（Update）」。

主题与插件不会自动安装新版本，需要分别更新；只更新 Inkstone 时无需点击「全部更新」。完成后，确认 Inkstone 和浅色仍被选中，再试一次划线或写想法。已从 GitHub 手动安装到 `themes/Inkstone/`、`plugins/inkstone-annotations/` 且插件 ID 未改的用户，可直接检查市场更新，无需卸载重装；保留插件的 `data.json`、已保存标注和个人设置。操作说明也可参考 Obsidian 官方的[社区插件](https://obsidian.md/help/community-plugins)与[主题](https://obsidian.md/help/themes)文档。

### 备选：GitHub Release 或安装脚本

独立插件由 [obsidian-inkstone-annotations](https://github.com/bufan1024/obsidian-inkstone-annotations) 发布，可从其 [Release](https://github.com/bufan1024/obsidian-inkstone-annotations/releases/latest) 获取三个运行文件。

手动安装时，将插件的三个运行文件放到以下目录：

```text
你的笔记库/
└── .obsidian/
    └── plugins/
        └── inkstone-annotations/
            ├── main.js
            ├── styles.css
            └── manifest.json
```

首次手动安装后，在「设置 → 第三方插件」中按需关闭「受限模式」，启用「Inkstone Annotations」。未出现在列表中时，重启 Obsidian，并检查目录是否多嵌套了一层。`.obsidian` 是隐藏目录；使用自定义配置文件夹时替换为实际名称。独立主题包不包含 JavaScript，也不会添加操作入口。

更新前关闭 Obsidian 并备份旧文件，只替换上述三个文件，保留 `data.json`。完整[阅读合集](https://github.com/bufan1024/obsidian-inkstone/releases/tag/1.4.0) `Inkstone-Reading-Kit-1.4.0.zip` 也包含插件 **1.2.0** 和主题 **1.4.0**。使用[上游主题仓库](https://github.com/bufan1024/obsidian-inkstone)或合集中的安装脚本时（本独立插件仓库不含安装器），可运行 `python3 scripts/install.py --vault "/你的笔记库路径" --update --plugin-only`，先加 `--dry-run` 可查看计划。它保留当前主题、配色、行宽偏好和插件数据，不会自动启用插件。完整步骤见[安装与更新教程](https://github.com/bufan1024/obsidian-inkstone/blob/main/INSTALL.md)。

## 添加标注与备注

1. 在笔记中选中同一源代码行内的普通文字。屏幕自动折行不影响选择，不要跨越手动换行。
2. 只需划线时，点击快捷条的「划线」，沿用最近的样式和颜色；要换样式，点击相邻箭头「划线样式」，选择下划线或黄、绿、蓝、粉色高亮，即可保存。
3. 需要备注时，在选中文字后点击「写想法」，直接在原文旁的小浮层中查看原文预览、输入多行想法，并选择黄、绿、蓝、粉色高亮或下划线。新普通选区默认下划线；已有标注默认当前样式，不改样式时会保留原有标记。
4. 点击「保存想法」，或按 `Cmd+Enter`（macOS）、`Ctrl+Enter`（Windows/Linux），一次保存选定的样式与脚注备注。输入期间切换样式不丢失文字，也不提前写入笔记；「取消」不写入任何样式或备注。

「写想法」就是添加备注，作为原生脚注保存在当前文件文末。点击正文脚注编号可跳转到备注，脚注处的返回链接可回到正文。

命令「墨读：写想法」与快捷条共用这个小浮层，原有 `add-note` 命令 ID 与快捷键绑定保留。命令「墨读：标注与想法」、右键「墨读：标注与想法…」和左侧荧光笔图标打开完整面板，可同时选择样式和填写想法。在完整面板中点击「保存标注」或按 `Cmd+Enter` / `Ctrl+Enter` 保存，取消不会写入笔记。

阅读视图支持同一源代码行的简单段落，可在已有 Inkstone 标记和脚注旁继续标注其他普通文字，不必为每次标注切换视图。含链接、加粗等复杂 Markdown 的段落仍请切到编辑视图，选择具体位置的普通文字。

## 编辑或移除已有标注

点击阅读视图或实时预览中显示的现有高亮、下划线，会在原文旁弹出小菜单；标记获得键盘焦点后，按 `Enter` 或空格也能打开。点击侧栏的「编辑」，会在该按钮旁打开相同的小菜单。

- 直接选择黄、绿、蓝、粉色或下划线，立即修改整条标注。当前样式显示选中提示。
- 点击「写想法」，在小菜单内查看原文预览、输入多行备注并选择样式；已有备注时显示「编辑想法」。默认选中当前样式，不改时会保留原有标记。此处切换样式只更新草稿，保留已输入的文字；点击「保存想法」或按 `Cmd+Enter` / `Ctrl+Enter` 后，样式与备注一起生效。「取消」不写入任何样式或备注。
- 点击「删除标注」移除标记并保留原文。

未编辑的小菜单可通过点击外部或滚动收起。输入想法或修改草稿样式后，点击外部、滚动或重新激活同一来源会保留草稿。已有标注的想法编辑点「取消」会返回父菜单，再次进入仍可继续本地草稿；取消时不写入笔记，也不把取消状态加入恢复列表。明确关闭整个菜单、按 `Esc`，或取消新选区的想法，才会放弃当前草稿；`Esc` 关闭后恢复原来的键盘焦点。切换笔记或原文变化后仍不能保存过期内容，需要从当前原文重新打开。阅读视图右键的编辑入口与综合编辑命令仍打开完整面板，可同时修改样式与想法。

在编辑视图中，将光标放入已有标记的正文，或选中其部分正文，再执行标注命令，会修改整个已有标记，不会嵌套一层标记。不要把 HTML 标签本身包含在选区中。

移除标注会保留原文，只清理不再被其他位置引用的 Inkstone 专属脚注。若多个位置共享同一备注，移除其中一个标记不会删除其余位置需要的备注；单独修改其中一个标记的备注，会为它建立独立脚注。

### 恢复本次会话的想法草稿

正在编辑的想法因切换笔记或原文变化而关闭时，插件会暂存想法纯文字和当时的原文预览。执行「墨读：恢复会话想法草稿」，找到对应文件，点击「复制草稿」；回到原笔记，**重新选择当前原文**，再打开「写想法」粘贴并保存。恢复窗口不会按旧选区自动写回；不再需要时可点击「丢弃草稿」。

暂存只存在于本次插件会话的内存中，最多保留 10 个文件，每个文件保留最近一份；超过上限时移除最早的一份。明确关闭整个菜单、按 `Esc` 或取消新选区的想法会丢弃当前草稿，不进入恢复列表；已有标注编辑的「取消」只返回父菜单，按上文保留本地输入。关闭或重启插件、退出 Obsidian 后不会保留会话草稿。它不替代持久备份。

## 实时预览与源码模式

实时预览（Live Preview）中，光标和选区离开标注范围后，显示实际高亮或下划线；光标或选区进入范围时显示原 HTML 源码，便于直接编辑。源码模式始终显示原始内容。此显示切换不改写保存格式，也不需要转换旧笔记。

## 当前笔记侧栏与摘录导出

执行「墨读：打开标注侧栏」，或点击快捷条的「更多 → 打开标注侧栏」。侧栏仅列出当前 Markdown 笔记的标注，显示摘录、颜色或下划线样式及备注，并随笔记修改刷新。

顶部显示当前笔记名、所在目录和筛选条数／标注总数；悬停路径可查看完整位置。摘录与想法分层显示，定位、编辑和删除按钮始终可见。列表可单独滚动，顶部的搜索、筛选与导出入口保持可见。当前笔记刷新时保留控件及其键盘焦点；内容未变化时不重建列表。

- 在搜索框输入文字，同时搜索摘录原文和想法内容；忽略大小写与首尾空白。
- 使用颜色／下划线筛选框，或勾选「仅有想法」。搜索、样式与想法条件按 **AND** 组合，只显示同时满足条件的标注。
- 「定位原文」跳到标记位置；「编辑」在按钮旁打开[标注小菜单](#编辑或移除已有标注)，首层改色立即生效，写／编辑想法在同一浮层内保存，取消不写入；「删除」移除标注并保留原文。
- 切换到另一篇笔记时，侧栏跟随当前笔记，并重置搜索、样式和「仅有想法」条件。搜索范围始终是当前笔记。

侧栏「导出全部」按钮、快捷条「更多 → 导出当前笔记摘录」及同名命令会导出当前笔记的**全部标注**，不受搜索、样式或「仅有想法」条件影响。导出按钮的说明标明全部条数。新文件与原笔记放在同一目录，保留标注原文和 Markdown 备注，并包含来源链接、ISO 格式的快照生成时间，以及每条标注最近的章节路径和标题链接；无可用标题时保留笔记来源。

文件名为 `原笔记名-墨读摘录.md`；已有同名文件时，依次尝试 `原笔记名-墨读摘录-2.md` 等名称。导出会新建文件并打开，不覆盖原笔记或以前的摘录。摘录是当时的副本，不随原笔记自动同步。

标题链接由 Obsidian 的链接 API 生成。**同一笔记有重复同名标题时，链接只能跳到首个同名标题**；导出中的章节路径文字仍按标注所在位置显示。插件不会给原笔记插入块 ID 来消除这一限制。

### 汇总笔记或文件夹

1. 执行「墨读：汇总笔记或文件夹摘录」，在选择器中选择一篇 Markdown 笔记或一个文件夹；文件夹会包含其子目录中的 Markdown 笔记。
2. 也可在文件树选中一个或多个笔记、文件夹，右键选择「汇总墨读摘录」。重复选中的笔记只汇总一次，没有墨读标注的笔记会跳过。
3. 插件在笔记库根目录新建并打开 `墨读摘录汇总.md`；重名时加 `-2` 等编号。每篇来源笔记保留各自的原文链接、章节路径和全部标注、备注。

这是手动生成的快照，不建立全库索引，不持续扫描或自动同步，也不覆盖原笔记或已有汇总。

## 快捷条、阅读设置与翻页

有效选区后会显示快捷条，操作时保留选区。首层提供「复制」「划线」「写想法」和「更多」；划线旁的箭头展开带文字的小色点与下划线选项，选择后立即保存。「划线」沿用最近的样式和颜色，已有标记则保留现有样式；「写想法」直接打开含原文预览、多行输入框和样式选择的小浮层，点击保存后样式与备注一起生效。已有标记还可从「更多」移除。直接点击正文中的现有标记，会打开[标注小菜单](#编辑或移除已有标注)。

快捷条、菜单和侧栏使用随界面字号缩放的文字与统一间距。快捷条位于选区上方，空间不足时移到下方，也提供触控入口。普通快捷条可按 `Esc` 或滚动收起；正在编辑的想法按[草稿保留规则](#编辑或移除已有标注)处理。在插件设置中关闭「快捷标注条」后，仍可使用右键菜单和命令面板。

字号和字体使用 Obsidian「设置 → 外观」的原生控制。Inkstone 主题仍支持 CSS 变量 `--inkstone-font-size` 显式覆盖字号；要恢复原生字号，请移除已有的该变量。

插件设置中的行高和行宽预设用于 Inkstone 主题：

| 设置 | 选项 |
| --- | --- |
| 阅读行高 | 跟随主题 / CSS、1.5、1.75、2.0 |
| 阅读行宽 | 跟随主题 / CSS、32em、40em、48em |
| 恢复阅读预设 | 恢复主题或 CSS 的行高与行宽，保留原生字号和字体 |

使用行宽预设时，请开启「设置 → 编辑器 → 可读行宽」。如果用 CSS 自定义行高、行宽，将插件预设设为「跟随主题 / CSS」。

在「设置 → Inkstone Annotations」中可显式选择界面语言「简体中文」或 **English**；默认使用中文，不跟随 Obsidian 的语言自动切换。选择语言后重启插件（关闭再启用），命令面板中的名称会随之刷新；原有命令 ID 和快捷键绑定不变。

「颜色含义」可把四色显示为「重点」「待核实」等自定义别名。留空恢复默认名称；别名会用于标注菜单、侧栏与摘录中的样式标签。它只改变显示名称，不改笔记中的颜色类名、HTML 或脚注格式，也不改变筛选所对应的实际颜色。

执行「墨读：上一屏／下一屏」，或点击状态栏 ↑／↓，按当前内容视口高度立即滚动，并保留少量上下文。阅读视图和编辑视图都可使用；这不会给笔记插入分页符。翻页命令没有默认快捷键，可在「设置 → 快捷键」中自行绑定。

要逐条回看当前笔记，执行「墨读：上一条标注／下一条标注」。编辑视图按光标位置查找，阅读视图按当前标注或可见位置查找；到第一条或最后一条时提示边界，**不会循环跳转**。这两个命令也没有默认快捷键，可自行绑定。

## 完整命令与撤销

插件提供 17 个命令，均可在命令面板中查找并自行绑定快捷键，没有默认专属快捷键。下表使用默认中文名称：

| 命令 | 操作 |
| --- | --- |
| 墨读：标注与想法 | 打开标注面板，记住最近使用的样式和颜色 |
| 墨读：添加下划线 | 直接划线，或将现有标注改为下划线 |
| 墨读：黄色高亮 | 直接添加或改为黄色高亮 |
| 墨读：绿色高亮 | 直接添加或改为绿色高亮 |
| 墨读：蓝色高亮 | 直接添加或改为蓝色高亮 |
| 墨读：粉色高亮 | 直接添加或改为粉色高亮 |
| 墨读：写想法 | 打开小浮层填写想法，新普通选区默认下划线；保留 `add-note` 命令 ID |
| 墨读：切换彩色／灰阶标注 | 切换当前显示方式，不改保存的颜色 |
| 墨读：撤销上次标注 | 撤销最近一次添加、编辑或移除标注 |
| 墨读：打开标注侧栏 | 查看当前笔记标注 |
| 墨读：导出当前笔记摘录 | 新建含全部标注、备注及来源的 Markdown |
| 墨读：上一条标注 | 定位前一条标注，不循环；ID `previous-annotation` |
| 墨读：下一条标注 | 定位后一条标注，不循环；ID `next-annotation` |
| 墨读：恢复会话想法草稿 | 查看并复制会话内暂存的想法；ID `restore-thought-draft` |
| 墨读：汇总笔记或文件夹摘录 | 手动选择来源并生成摘录快照；ID `collect-excerpts` |
| 墨读：上一屏 | 向前滚动一屏，保留少量上下文 |
| 墨读：下一屏 | 向后滚动一屏，保留少量上下文 |

编辑视图可以使用系统撤销与重做：`Cmd+Z` / `Ctrl+Z` 及系统对应的重做快捷键。每次标注的正文与脚注修改作为一次编辑操作处理。

阅读视图可执行「墨读：撤销上次标注」。它只保留本次启用插件以来的最后一次标注操作，须在同一笔记且之后没有其他修改时使用；若有其他编辑，请切换编辑视图使用系统撤销。它不提供多步标注历史，也不负责删除导出的摘录文件。

## 彩色与墨水屏显示

默认使用浅色高亮底色与深色正文。开启面板或插件设置中的「墨水屏显示」后，四色统一为浅灰底，并通过底线保留区别：

| 高亮颜色 | 灰阶底线 |
| --- | --- |
| 黄色 | 实线 |
| 绿色 | 双线 |
| 蓝色 | 点线 |
| 粉色 | 虚线 |

切换显示不会改变 Markdown 中保存的颜色，之后可恢复彩色。插件关闭后，Inkstone 主题仍能显示保存的 HTML 标记与原生脚注。

## 保存格式与保护范围

下划线和高亮使用 HTML，备注使用 Obsidian 原生脚注，继续兼容旧版格式：

```md
<u class="inkstone-underline">需要回头思考的句子</u>[^inkstone-demo-1]

<mark class="inkstone-highlight inkstone-yellow">值得记住的观点</mark>

[^inkstone-demo-1]: 我对这句话的理解。
```

颜色类名为 `inkstone-yellow`、`inkstone-green`、`inkstone-blue`、`inkstone-rose`。可以在源码模式直接编辑标记与脚注。普通脚注可以共享；保留其余引用时，插件不会删除共享定义。

选区应仅包含同一源代码行内的普通正文。插件保护 HTML 标签及属性、注释、不受支持的 HTML 内部文字、链接目标与引用标识、代码、公式和属性区；不接受跨行选区或包含完整 Markdown / HTML 格式的选区。标题、列表和引用的结构符号应留在选区外。错误提示会说明具体原因和重选方式；切换编辑视图后仍需避开受保护内容。

阅读视图按原生渲染器提供的源段落位置和逐字符映射定位，重复词语可区分；复杂 Markdown、未知 HTML 或跨源行段落继续要求切到编辑视图。菜单或面板打开后切换笔记、关闭插件或修改原文，保存会被拒绝，需要重新选择。

复制 [划线与备注示例](examples/划线与备注示例.md) 到笔记库，可练习同段多次标注、编辑、侧栏和导出。测试范围见项目[验证记录](https://github.com/bufan1024/obsidian-inkstone/blob/main/VALIDATION.md)。窄屏与触控事件测试不等于手机原生应用或实体墨水屏实测，两类设备尚未验证。

## 开发与许可

使用 Node.js 22 或更新版本，无需安装依赖：

```sh
node build.mjs
node --test tests/*.test.cjs
```

也可运行 `npm run build` 和 `npm test`。构建仅使用本仓库的 `src/` 和 `manifest.json`，生成 `main.js` 与 `styles.css`。

插件源码只在[上游 annotations 目录](https://github.com/bufan1024/obsidian-inkstone/tree/main/annotations)维护。请在那里提交源码修改，再用上游 `scripts/export_plugin.py` 重新导出此发行仓库，避免维护两份不同的源码。本地示例是上游示例的导出副本。
